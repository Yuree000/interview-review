# Security Policy

## Supported Use

This repository is intended for local development and self-hosted use.

## Secrets

- Do not commit `.env`
- Do not commit cloud credentials
- Do not commit real interview recordings, transcripts, reports, or resumes
- Rotate any credential that was accidentally exposed

## Sensitive Data

Interview media and generated review artifacts may contain personal, company, or confidential information. Treat everything under runtime output directories as sensitive unless it is synthetic test data.

## Reporting

If you find a security issue, please report it privately to the repository owner before opening a public issue.
